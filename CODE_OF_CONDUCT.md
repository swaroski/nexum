# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and focus
criticism on ideas and code rather than people. Harassment and
discrimination are not tolerated.

Report unacceptable behavior privately to the maintainers via
[GitHub Security Advisories](https://github.com/swaroski/nexum/security/advisories/new)
or by contacting a maintainer directly. Reports are handled confidentially.
